# NetCarve Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking. Each numbered Task
> ends with a green test run, a version bump, a commit, a tag and a push.

**Goal:** Ship a Manifest V3 Chrome extension that calculates IPv4/IPv6 subnets, plans address
space visually with persistent projects, solves VLSM and detects CIDR conflicts — entirely
on-device, with zero runtime dependencies for IP mathematics.

**Architecture:** WXT (MV3) hosts three entrypoints — a compact popup calculator, a full-page
hash-routed app (`#/calc`, `#/planner/:id`, `#/vlsm`, `#/conflicts`, `#/settings`) and a
background service worker that owns only the context menu. All domain logic lives in pure,
framework-free TypeScript under `src/lib/**` (IP maths, planner tree, VLSM solver, conflict
sweep, export, storage) and is covered by Vitest; Preact components under `src/ui/**` are thin
views over that logic. IPv4 is `number` with unsigned semantics, IPv6 is `bigint`.

**Tech Stack:** WXT · TypeScript (strict) · Preact + hooks · Vitest + @testing-library/preact ·
plain CSS custom properties. No runtime dependencies for IP maths, no CSS framework, no network.

**Spec:** `docs/spec.md` (verbatim copy of the product specification v1.0)

## Global Constraints

- Manifest permissions are exactly `["storage", "contextMenus"]` — nothing else (NFR-PERM-01).
- Zero runtime network requests; no remote fonts, no analytics (NFR-PERM-02, NFR-PRIV-01).
- TypeScript `strict`; **no `any` in `src/lib/**`**.
- `src/lib/ip/**` must reach **100 % branch coverage**; CI fails below that (NFR-QUAL-01).
- All user-facing copy in **British English**, sourced from a single `src/strings.ts` (NFR-I18N-01).
- Addresses always rendered in a `ui-monospace` stack.
- Total gzipped bundle < 150 KB (NFR-SIZE-01).
- Planner palette is exactly 8 tokens: `blue green amber red violet teal pink grey`.
- Colour selection is always a **visual swatch picker**, never a text field (user global rule).
- Every full-shell app page carries the attv.uk credit footer (user global rule).
- Release management: SemVer from `v0.0.1`, `CHANGELOG.md` (Keep a Changelog 1.1.0), an
  annotated git tag and a GitHub Release per task.

## Task 2 — `lib/ip`: errors + IPv4 parse/format/mask

**Produces:** `ParseError`, `isParseError`, `parseIPv4`, `formatIPv4`, `maskV4`, `parseV4Mask`.

- [ ] Tests first: valid quads (`0.0.0.0`, `255.255.255.255`, `192.168.1.37`); rejections —
      leading zeros `010.1.1.1` → `BAD_OCTET`, shorthand `10.1` → `BAD_FORM`, `256.1.1.1`,
      whitespace padding, empty octets, non-digits, `1.2.3.4.5`.
- [ ] `maskV4(0) === 0`, `maskV4(24) === 0xFFFFFF00`, `maskV4(32) === 0xFFFFFFFF`.
- [ ] `parseV4Mask('255.255.255.0') === 24`; `255.0.255.0` → `NONCONTIGUOUS_MASK`.
- [ ] Implement, run tests green, commit, `v0.0.2`, tag, push, release.

## Task 3 — `lib/ip`: IPv6 parse + RFC 5952 format

**Produces:** `parseIPv6`, `formatIPv6`, `expandIPv6`, `maskV6`, `MAX128`.

- [ ] Tests: full form, `::`, `::1`, `2001:db8::1`, embedded IPv4 tail `::ffff:192.0.2.1`,
      uppercase input, zone id `fe80::1%eth0` → parses with warning `ZONE_ID_STRIPPED`.
- [ ] Rejections: double `::` → `DOUBLE_COMPRESSION`, 9 groups, `:::`, bad hextet `zzzz`,
      5-digit hextet, embedded IPv4 not in tail position.
- [ ] RFC 5952: lowercase, no leading zeros, longest zero-run compressed, leftmost run on tie,
      single zero group **never** compressed (`2001:db8:0:1:1:1:1:1`), `2001:db8:0:0:1::1`.
- [ ] Implement, green, commit, `v0.0.3`, tag, push, release.

## Task 4 — `lib/ip`: Cidr type + parseCidr + formatCidr

## Task 5 — `lib/ip`: arithmetic + relations + split

**Produces:** `networkOf`, `lastAddressOf`, `usableRange`, `totalAddresses`, `contains`,
`relationOf`, `splitOnce`, `compareCidr`, `wildcardV4`.

- [ ] Tests cover every §4.4 row: v4 `/31` (2 usable, RFC 3021), `/32` (1, host route),
      `/30` and shorter (total − 2), `/0`; v6 `/127`, `/128`, `/64`, usable === total.
- [ ] `relationOf` — identical, a-contains-b, b-contains-a, disjoint, cross-family disjoint.

- [ ] `splitOnce('10.0.0.0/8')` → `10.0.0.0/9`, `10.128.0.0/9`; at max prefix → error.
- [ ] Implement, green, commit, `v0.0.5`, tag, push, release.
